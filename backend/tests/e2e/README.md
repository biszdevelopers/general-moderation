Phase 2 cases are golden-master characterization tests generated by
`tests/tools/phase2_generator.py`, exercising the wired FastAPI app through
`TestClient` across the 26-language matrix, batch sizes 1-100, validation
edges, profiling flows, and response shapes.

## Adding New Tests
E2E tests use the `client` fixture (a wired FastAPI `TestClient`). Public
requests use snake_case field names (`user_id`, `app_name`). New Phase 2
cases (multi-app scenarios, SPA fallback) go in `test_public_api_part_3.py`
and `test_admin_part_2.py`.
