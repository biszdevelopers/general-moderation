Phase 2 cases are golden-master characterization tests generated by
`tests/tools/phase2_generator.py`. Expected values were captured by running the
real application at generation time, so the suite reproduces observed behavior
and locks it in as regression coverage. Dimension matrices use the 26-language
expanded set, full text-length ranges, obfuscation/encoded content, edit
distances 1-3, all semantic categories, window lengths 1-365 and user/app
counts up to 1,000.

`BaseTest` frozen clock for time-sensitive logic and the engine/word bank
fixtures from `conftest.py`.
